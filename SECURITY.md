# Security Policy

## Scope

AST Auditor is an independent, early-stage static analysis project. It is provided for security research and developer assistance and is not a complete security assessment tool. Please read the limitations in [README.md](README.md) and [SECURITY_REVIEW.md](SECURITY_REVIEW.md).

## Reporting a vulnerability

Please do not publish exploit details, credentials, private data, or a weaponized proof of concept in a public issue.

If GitHub's **private vulnerability reporting** feature is enabled for this repository, use it to send a confidential report. If it is not enabled, contact the repository maintainer through the GitHub profile and ask for a private reporting channel before sharing sensitive details.

A useful report includes:
- A concise description and potential impact.
- The affected commit, version, or file.
- Reproduction steps using a harmless, isolated test case.
- Any suggested mitigation.

Please allow a reasonable amount of time for investigation and coordinated disclosure. Do not include real secrets or third-party data in reports.

## Supported versions

Security fixes are prioritized for the latest version on the default branch. Older versions may not receive backports.
